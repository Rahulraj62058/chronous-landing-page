# Chronos Watches ⌚

A modern and responsive luxury watch landing page built with HTML5 and
CSS3.

## ✨ Features

-   Modern luxury watch design
-   Light and dark split hero section
-   Custom SVG watch illustrations
-   Watch collection with pricing
-   Product cards
-   Add to Cart interface
-   Login/Register interface
-   Profile section
-   Watch specifications
-   Responsive design
-   Smooth navigation
-   CSS-only interactive overlays
-   No JavaScript required

## 🛠️ Technologies Used

-   HTML5
-   CSS3
-   SVG
-   Google Fonts
    -   Bebas Neue
    -   Inter

## 🚀 Run Locally

1.  Clone the repository:

``` bash
git clone https://github.com/YOUR-USERNAME/Chronos-landing-page.git
```

2.  Open the project folder:

``` bash
cd Chronos-landing-page
```

3.  Open `index.html` in your browser, or use VS Code Live Server.

## 🌐 GitHub Pages

This project can be deployed using GitHub Pages.

Go to:

**Repository → Settings → Pages**

Select:

``` text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

Then click **Save**.
